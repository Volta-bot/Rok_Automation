ROKauto - portable Windows x64 application

1. Extract the entire ZIP to a folder. Do not run from inside the ZIP.
2. Start MuMu Player with Rise of Kingdoms installed and signed in.
3. Enable local ADB debugging in MuMu and use Vietnamese in-game language.
   Use a landscape 16:9 emulator display.
4. Double-click ROKauto.exe, select your instance, and start your task.

Python is included. No Python installation or pip commands are needed.
Keep ROKauto-worker.exe and the _internal folder beside ROKauto.exe.
OCR models are included; no model download is required at first launch.

Settings, account progress, and screenshots are saved in:
  %LOCALAPPDATA%\ROKauto
Treat those files as private. They are not included in this download.
To update, extract a new release into a new folder. Saved progress is retained.
MuMu Player and Rise of Kingdoms are not included.

Command-line diagnostics are available through ROKauto-worker.exe --help.
